「いつ動き出すか」を決める仕組み

GitHub Actions スケジュール実行

GitHub Actionsのcronスケジュール機能を使い、 誰も操作しなくても自動的に起動します。 手動でも「Run workflow」ボタンから即時起動が可能です。

# 3時間おきに自動実行
schedule:
- cron: '0 */3 * * *'
# 手動トリガーも可能
workflow_dispatch: {}

1日の起動タイミング

{[['00:00', true], ['03:00', false], ['06:00', false], ['09:00', true], ['12:00', false], ['15:00', false], ['18:00', true], ['21:00', false]].map(([t, active]) => `
${t} JST ${active ? '⚡ 起動' : ''}
`).join('')}
⚙️ 自動スケジュール 👆 手動起動も可 🆓 無料枠で動作（パブリックリポジトリ）

💡 RSSフィードとは？

ブログ・ニュースサイトが公開している「新着記事の一覧データ」。 タイトル・要約・URLが構造化されており、プログラムで自動取得できます。 メディアが更新するたびに自動で最新情報が流れてきます。

📰 17メディア ⏱ 過去3時間以内の記事のみ 🆓 無料で取得可能

PART 3

処理する場所

⚙️

「何をして、何を選ぶか」

収集した記事をGitHub Actions上でNode.jsスクリプトが処理し、 Gemini AIが価値ある記事を3〜5件に絞り込んで日本語で要約します。

A

📥 記事の収集（fetch-feeds.js）

17のRSSフィードをスキャンし、過去3時間以内の記事をカテゴリ別に整理。タイトル・要約・URLを抽出して一時ファイルに保存。

↓
B

🤖 Gemini AIで選定・要約（Gemini 2.5 Flash）

収集した全記事をAIが分析。以下の基準で3〜5件を選んで日本語要約を作成：

新モデル・新機能の発表 重要なアップデート 実践的なTips 業界トレンド

⚠️ 価値ある記事が0件の場合は送信をスキップ（LINE通知なし）

↓
C

📝 メッセージ生成

AIが生成した要約をLINE送信用テキストに整形。5000字を超える場合は自動的に複数メッセージに分割。

## 実行環境 (GitHub Actions)
runs-on: ubuntu-latest
node-version: '20'
## 使用API
Gemini 2.5 Flash ← Google AI Studio
## 環境変数（GitHub Secrets）
GEMINI_API_KEY
LINE_CHANNEL_ACCESS_TOKEN
LINE_USER_ID
